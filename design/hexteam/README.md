Оригинальные SVG выгружены из Figma без изменения. Android использует их PNG-рендеры 4× из `res/drawable-nodpi`. `asset-map.json` перечисляет используемые ресурсы, размеры оригиналов и места вызова. PNG можно воспроизвести командой `rsvg-convert -z 4 input.svg -o output.png`. Golos Text поставляется локально с лицензией OFL; загрузки шрифта или иконок при запуске нет.

Системные панели рисует Android. Волна диктофона, положение ползунка, длительности, названия, участники и текст — реальные данные приложения. Цвет плеерных иконок в тёмной теме адаптируется к цвету текста. Название GigaChat из макета исправлено на GigaAM, фактически используемую модель распознавания.

Список/сетка и сортировка используют существующий DataStore. Избранное добавлено в тот же DataStore без миграции Room. Долгое нажатие карточки открывает подтверждение удаления; долгое нажатие реплики — переименование участника. Дополнительные параметры обработки и экспорта доступны из меню.

`HexUiTest` отрисовывает настоящие Compose-компоненты через Robolectric Native Graphics и проверяет события контролов. Снимки сохраняются в `src/app/build/hexteam-screenshots`. Эти тесты проверяют UI на компьютере, а не микрофон, модели или производительность телефона.
