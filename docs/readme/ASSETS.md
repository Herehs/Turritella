# Изображения README

Светлое оформление обновлено 7 ноября 2026 года. В README используются три предоставленных макета и исходный SVG-логотип Turritella.

## Источники

| Файл в комплекте | Предоставленный исходник | Использование |
| --- | --- | --- |
| `logo.svg` | `Vector.svg` | Исходный логотип; также встроен в обложку на синей плашке |
| `screen-main.svg` | `hex-team-main-screen(2).svg` | Сетка записей |
| `screen-recording.svg` | `hex-team-dict-screen.svg` | Запись разговора |
| `screen-transcript.svg` | `hex-team-transcript-lyrics-concept.svg` | Просмотр расшифровки |

Эти четыре SVG сохранены без изменения содержимого. Для отображения в README из экранов получены PNG размером 824 × 1834 пикселя. Текст, цвета, расположение элементов и пропорции исходных макетов сохранены.

[Проект в Figma](https://www.figma.com/design/8BSujn5ZYzhyfhggu5RsnC/my_projects?node-id=387-2453).

## Оформление

| Файл | Описание |
| --- | --- |
| `hero.svg` | Векторная обложка: белый фон, исходный логотип, название и слоган |
| `hero.png` | Растровая версия обложки для Markdown |
| `pipeline.svg` | Схема зависимостей локального конвейера в светлой палитре |
| `screen-*.png` | PNG-версии соответствующих SVG-макетов |

Обложка собрана средствами SVG. Логотип встроен с сохранением исходной геометрии и цвета; синяя плашка обеспечивает контраст светлого знака на белой обложке. Схема построена по исходному коду приложения.

Экранные изображения показывают дизайн из Figma. Тексты разговоров, даты, таймер и остальные значения в макетах демонстрационные; они не являются результатами измерений приложения. Состояние интеграции интерфейса указано в README.

## Установка в репозиторий

Распакуйте архив в корень репозитория: он содержит `README.md` и каталог `docs/readme/`. Относительные ссылки на изображения сохранятся.

Существующие документы `docs/ARCHITECTURE.md`, `docs/UI_CONTRACT.md`, `docs/LIMITATIONS.md` не изменялись и не входят в архив обновления. Для технического описания использован коммит `2f6db208a7b8e6ab8649b2664ba69348e99752c6`; при подготовке обновления проверено, что это текущий коммит `origin/main`.
