# Ограничения и проверка

APK предназначен для интеграции с интерфейсом. На этой машине проверяются сборка, подпись APK, наличие моделей и JVM-тесты. Для допуска к демонстрации нужен прогон на чистом arm64-телефоне в авиарежиме. Проверка экранов, записи при погашенном экране, аудиофокуса, системного экспорта и докачки с обрывом требует устройства и готового UI.

Аудиобуфер хранится в памяти целиком. Потребление памяти растёт с длительностью диалога, а память LLM зависит от устройства. При перекрытиях голосов возможны дубликаты и ошибки атрибуции. Короткие ответы, далёкий микрофон, шум и похожие голоса могут ухудшить границы. Автоматическая оценка числа участников требует проверки на живых диалогах. Предобработка отключена до замера её влияния.

## Измерение качества

На телефоне прогоните 3–5 диалогов с ручной разметкой в формате основного JSON. Обязательно включите короткие ответы, паузу, тихую речь и перебивание. Прогон до/после должен использовать один телефон и те же WAV. Для сравнения пунктуации и Whisper меняйте по одной настройке.

```sh
python -m venv .venv
.venv/bin/pip install -r tools/eval/requirements.txt
.venv/bin/python tools/eval/wer.py reference.json result.json
.venv/bin/python tools/eval/der.py reference.json result.json
```

WER сравнивает слова без регистра и пунктуации, ё приравнивается к е, числа сохраняются в написанном виде. DER использует оптимальное взаимно-однозначное соответствие говорящих с учётом перекрытий, без допуска у границ. RTF берётся из metrics.json, включает подготовку во время обработки и зависит от того, был ли первый запуск холодным. Для оценки меток отдельно сравните начало и конец соответствующих реплик в миллисекундах.

| Конфигурация | WER | DER | RTF |
|---|---|---|---|
| GigaAM, пунктуация выключена | ожидает прогона | ожидает прогона | ожидает прогона |
| GigaAM + Qwen | ожидает прогона | ожидает прогона | ожидает прогона |
| Whisper small + Qwen | ожидает прогона | ожидает прогона | ожидает прогона |

Сравнение двух LLM и демонстрационное видео остаются этапами проверки на устройстве. Preview-данные и результаты модульных тестов в таблицу качества не включаются.
